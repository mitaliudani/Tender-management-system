# Security reporting

The Tender Management System is an incomplete educational codebase, not an approved production target for security testing.

If you discover a problem in this repository, please use GitHub's private vulnerability reporting feature if enabled, or email the maintainer at **mitali@chitthi.me**. Do not publish credentials, personal data or unpatched exploits in issues or pull requests.

Provide the affected source file, observed behavior, potential impact, and a minimal safe reproduction using synthetic data. Do not test third-party infrastructure or other users' accounts. This policy does not authorize intrusive testing or establish a bug-bounty program.

The source scanner is a limited signature-based aid. A passing scan does not certify the application's security.
